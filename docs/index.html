FG Reference List
Former versions of SKUs in the FG list, so the BOM tab can cost them and compare old against new. CSV columns: item_id, reference_of, item_name — no header. reference_of is the internal ID of the current FG this one replaced. Reference SKUs are selectable as the main finished good as well as the comparison. They affect the BOM tab only: availability, manufacturing and S&OP are untouched.

Embargo List
SKUs with availability gated until a specific date. CSV format: internal_id,embargo_date (YYYY-MM-DD)
Embargoed items: 0
Overrides
Manually override an FG's availability, bypassing all calculation. CSV format (no header), 5 columns: Internal ID, Location, Overridden Today Avail, Overridden Next Avail, Overridden Next Qty. Location is Verrayes or USA - 3PL. Next Avail is a date (YYYY-MM-DD). A blank value is overridden to empty. Open Demand is kept from live data; Max Build, Committable, Top Constraint and the staircase are blanked. Overridden SKUs are flagged with ✎ in the table.
Overridden items: 0
S&OP · Budget
Revenue budget for the S&OP Demand Review. CSV with header: month,location,channel,class,value,units. month = YYYY-MM; location = Verrayes or USA - 3PL; channel = B2B or DTC; value in the location currency (€ / $); units optional. Stored in sop_config.json.
Budget rows: 0
S&OP · Production Capacity
Rough-cut monthly capacity per class (VERRAYES production). CSV with header: month,class,capacity_units. Months without a row show no capacity line. Include shutdown months (e.g. August) with reduced or zero capacity.
Capacity rows: 0
S&OP · Legacy Sales History
Pre-NetSuite invoiced sales (2023–2024) for seasonality and YoY. CSV with header: month,location,channel,class,value,units. Class names may include legacy-only classes; they display as-is. Rendered muted in charts.
Legacy rows: 0
S&OP · Inventory Cover Targets
Weeks-of-cover policy bands per class, used to color the Projected Inventory view. CSV with header: class,min_weeks,max_weeks.

Planning FX (EUR per 1 USD): reserved for a future consolidated view
